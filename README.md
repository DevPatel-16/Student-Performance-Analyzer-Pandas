# Student Performance Analyzer

A beginner-friendly data analysis project built using Python, Pandas, NumPy, and Jupyter Notebook.

## Features
- Load student data from a CSV file.
- Detect missing values and duplicate records.
- Clean and prepare the dataset.
- Calculate total and average marks.
- Assign grades to students.
- Determine Pass/Fail results.
- Filter and sort student records.
- Analyze subject performance.

## Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook

## How to Run
1. Install the required libraries.
2. Open `students_performance.ipynb` in VS Code.
3. Ensure `Students.csv` is in the same folder.
4. Run the notebook cells in order.

## Dataset
The dataset contains sample student records for educational purposes.
